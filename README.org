Insert Elisp evaluation results as comments in your scratch buffer.

[[https://raw.githubusercontent.com/conao3/files/master/blob/scratch-comment.el/scratch-comment.gif]]

* Overview

When working in Emacs' scratch buffer, the default ~C-j~ (~eval-print-last-sexp~) inserts evaluation results directly into the buffer. This can clutter your workspace and make it harder to re-evaluate expressions.

~scratch-comment.el~ provides an alternative: evaluation results are inserted as properly formatted comments, keeping your code clean and re-evaluatable.

#+begin_example
;; Before (with eval-print-last-sexp):
(+ 1 2)
3

;; After (with scratch-comment):
(+ 1 2)
;;=> 3
#+end_example

* Requirements

- Emacs 26.1 or later

* Installation

** Using package.el (MELPA)

#+begin_src emacs-lisp
(package-install 'scratch-comment)
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package scratch-comment
  :ensure t
  :bind (:map lisp-interaction-mode-map
              ("C-j" . scratch-comment-eval-sexp)))
#+end_src

** Using leaf

#+begin_src emacs-lisp
(leaf scratch-comment
  :ensure t
  :bind ((lisp-interaction-mode-map
          :package elisp-mode
          ("C-j" . scratch-comment-eval-sexp))))
#+end_src

** Manual Installation

Clone this repository and add the directory to your ~load-path~:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/scratch-comment.el")
(require 'scratch-comment)
(define-key lisp-interaction-mode-map (kbd "C-j") 'scratch-comment-eval-sexp)
#+end_src

* Usage

Simply press ~C-j~ after an Elisp expression in ~lisp-interaction-mode~ (the scratch buffer). The result will be inserted as a comment on the following line.

For multi-line output (such as from ~princ~), each line is properly prefixed:

#+begin_example
(progn (princ "hello\nworld") t)
;;=> hello
;;   world
;;   t
#+end_example

To restore the default behavior:

#+begin_src emacs-lisp
(define-key lisp-interaction-mode-map (kbd "C-j") 'eval-print-last-sexp)
#+end_src
